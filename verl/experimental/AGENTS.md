# 实验模块约束

继承仓库根目录 AGENTS.md 的全部要求，尤其是“实验代码设计约束”。

- 每项实验放在独立子包内；文件按职责组织，避免单一大文件承载整套流程。
- 数据与算法模块不导入 Ray 训练器或 worker；只接受普通数据、配置及窄接口回调。
- 训练器通过显式组合的控制器接入实验；控制器不得持有训练器对象或访问其私有成员。
- 分布式 checkpoint 的 worker 适配与采样/评分算法分开，依赖只能从适配层指向基础模块。
- 持久化格式变更须维护版本、完整性校验及对应恢复测试。

- 完全新增模块按关键逻辑单元审查注释覆盖，不按行数统计。公共接口、实验假设、状态切换、恢复限制及异常处理均需说明，简单代码不重复解释。
