## 4. 评价指标及判定

主质量指标：固定D256原EM、接受答案EM和task_success分别报告；无答案、动作可执行率、严重协议违规、异常循环；正常纠错成功率。异常循环由固定评价规则与盲法样例复核决定，不使用训练reward值代替。不要依靠结构合法率一个指标（旧日志门控99%而动作有效率88.8%）。

主稳定性指标：全micro有效模型token加权熵及与实际Loss一致的均值均明确标注；KL代理分位数/均值、logratio边界与clipfrac、裁剪前norm、实际update/skip、scaler、分量输出端梯度与固定参数样本变化。现有输出端梯度不是完整参数梯度、参数256元素样本不是全局更新范数。固定上下文合法搜索/回答概率探针只能解释确定合法行为，不能把正Advantage直接当合法动作标签。

长度：分别统计模型有效token、环境token、最终回答token、每轮finish_reason、强制final和长度上限命中；取中位/p90/p95。总response_length不等同模型生成长度，缩短回答本身不是成功指标。

成本：每次更新实际候选组、补采轮数、模型token、检索调用、GPU时间、唯一题/来源分布。先比较相同更新步数，再用独立匹配rollout/token预算实验或预算内实际检查点比较；不把不同更新数的结果当相同学习进度。评价额外GPU时间单独计入。

预先声明筛选目标（建议值，可在首次启动前锁定）：
- 固定评价无答案/明显异常循环率相对B或LK至少减半，基线必须有足够异常样本；若基线0异常，不能计算减半或宣称预防效果。
- 正确率非劣目标：下降不超过2个百分点；给逐题配对差异与95%置信区间，区间不能排除较大损害则结论不足，不能仅看点估计过线。
- 正常恢复能力不明显下降；错误率降低不能以禁止探索或总是提前回答为代价。
- 长程100新增步末段仍维持正常生成，3seed方向一致；单seed或20步改善仅称初步结果。
- KL变小、norm变小、训练reward升高不单独构成通过；强KL学不动也不是稳定性成功。
- 奖励组以独立task EM和质量指标比较，改奖励后不能直接拿新旧reward均值判胜。

统计：D256用逐题配对变化、McNemar及配对置信区间；多seed报告每seed结果与均值/区间，重复生成以题为簇，避免把同题多轨迹当独立题。对多个臂的筛选结论保留探索性质，独立长程seed验证最终候选。小样本无法证明非劣或减半时标证据不足。父模型、固定题清单与指标规则在训练前冻结。

## 5. 判定解释及保护

B也稳定且候选稳定：没有复现风险，只能证明这段预算内未观察到退化，不能称因果修复。
L有效：支持更新强度问题；K有效：支持参考约束不足；R有效：支持过程信号贡献；LKR比LK有效：奖励在目标超参数下增加收益。
KL下降但EM/恢复率下降：约束过强；Entropy升高但无效动作增加：探索质量变差；Reward上升但独立质量下降：奖励设计失败。

统一数值/显存/完整batch保护和经回放冻结的持续退化保护；所有组规则相同。被停止组保留完整结果与停止原因，不事后更换配置重跑覆盖失败，不把提前停止冒充长期稳定。退化保护是损害控制，主要机制仍是更新约束与训练信号。
