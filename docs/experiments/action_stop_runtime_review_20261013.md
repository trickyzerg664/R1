## 对回答的影响

匹配 317 道相同题目，每题比较 G8 答对次数：旧版 50.749%，新版 50.946%；304 道答对次数相同，9 道提高，4 道降低。仅表明当前样本中未见明显退化，不能证明长期训练效果不变，也不是独立测试集评测。

处理器在正式解析器认可完整合法的首个 `<search>…</search>` 或 `<answer>…</answer>` 后，才让下一 token 生成 EOS。合法动作完成前不修改采样 logits；纯思考且尚未出现合法完整动作时继续生成，未闭合动作或引用、嵌套、空动作及违规文本不使用该提前结束。是否执行动作遵循原解析器规则，并没有新增要求所有 `<think>` 必须闭合的规则。原流程本就只消费首个可执行动作，EOS 及动作之后的尾部排除在消费前缀及损失掩码之外。CPU 回归和实际 GPU 审计均检查这一关系。

采样流会因提前结束和请求调度变化而改变，不能承诺每条回答逐字相同。候选实际消费内容和检索规模几乎一致，首步训练更新无跳过、损失及梯度有限，支持当前优化保留了正常训练流程。
