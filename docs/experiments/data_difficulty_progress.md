## 同步时机及状态定义

**每次改代码／跑实验后必须同步文档。** 代码修改更新实现记录与本台账；实验执行更新单次运行记录与本台账。失败、中断、未验证均需登记。改变方案或执行方式时，同步对应方案或步骤文档。

状态使用：计划中、进行中、待验证、已完成、失败、暂停、阻塞。失败/暂停/阻塞必须写明原因、最后有效产物和恢复条件。

开始时登记任务及运行位置；阶段完成、标签切换、checkpoint 保存、失败、暂停、恢复、结束时同步。长任务每次进度检查均记录“检查时间 + 日志确认的进度”，不得用启动时间或预期耗时推算完成量。交接前同步总台账和单次记录，文档不能替代进程与产物检查。
